# MK4 · 오늘의 환율 정보판

[바로 보기](https://aleph-mk0915.vercel.app) · 2026-09-15 · HTML, CSS, JavaScript

오늘의 달러-원 환율을 보여 주는 한 장짜리 페이지입니다. 숫자만 띄우는 대신 그 숫자를 어디서, 언제 가져왔는지를 같이 보여 주는 데 초점을 맞췄습니다.

## 기능

| 카드 | 내용 |
| --- | --- |
| 오늘 값 | 환율, 출처 이름과 URL, 출처가 밝힌 시각, 내가 조회한 시각, 어제 대비 변화 |
| 일별 기록 | 한국 시간 기준 날짜로 묶고, 같은 날짜는 한 건으로 합침 |
| 실패 재현 | 시간 초과, 인증 오류, 요청 한도 초과, 오프라인, 응답 형식 오류 다섯 가지를 버튼으로 재현 |

데이터는 [Frankfurter API](https://frankfurter.dev)에서 받습니다.

## 신경 쓴 부분

출처 시각과 조회 시각을 나눠서 보여 줬습니다. 환율 API는 하루에 한 번 갱신되는 경우가 많아서, 방금 조회했더라도 값 자체는 어제 오후 것일 수 있습니다. 둘을 섞으면 오래된 값을 최신처럼 보여 주게 됩니다.

날짜는 모두 `Asia/Seoul` 기준으로 계산했습니다. 브라우저 시간대나 UTC를 그대로 쓰면 자정 근처에서 같은 날 값이 두 건으로 갈라지거나 날짜가 하루 밀립니다.

실패했을 때 마지막으로 받은 정상값은 지우지 않고, 상태만 "오래된 값"으로 바꾸고 어떤 실패인지 표시합니다. 실패 다섯 가지는 실제 서버를 망가뜨릴 수 없어서 미리 만든 가짜 응답으로 재현했습니다. 이 재현은 실제 환율 값에는 영향을 주지 않습니다. 다시 시도 버튼은 실패 상태일 때만 눌리게 했습니다.
