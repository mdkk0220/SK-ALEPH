# MK3 · 팬카드 스튜디오

[바로 보기](https://aleph-mk0914.vercel.app) · 2026-09-14 · React 18, Vite

사진 위에 문구를 올리고 크기, 색, 비율(1:1, 4:5, 9:16)을 정해 PNG 팬카드로 저장하는 앱입니다. 기능을 단계별로 쌓으면서 탭 다섯 개로 나눴습니다.

| 탭 | 내용 |
| --- | --- |
| 1 | 사진 올리기, 문구 편집, 드래그로 문구 위치 옮기기 |
| 2 | 미리보기와 저장된 PNG가 똑같이 나오게 맞추기 |
| 3 | 극단적인 입력 12가지 처리 |
| 4 | 템플릿 저장 · 수정 · 삭제 |
| 5 | 템플릿 JSON 내보내기 · 가져오기, 완성본 저장 |

## 신경 쓴 부분

핵심은 화면에 보이는 미리보기와 실제로 저장되는 PNG를 일치시키는 일이었습니다. 미리보기는 CSS로, 저장은 canvas로 그리기 때문에 같은 문구도 줄바꿈 위치나 좌표가 조금씩 어긋났습니다. 이렇게 맞췄습니다.

- 한글처럼 띄어쓰기 없이도 줄이 바뀌는 문구는 글자 단위로 감싸서 CSS 줄바꿈과 결과를 맞췄습니다.
- 글꼴이 다 불러와진 뒤에 그리게 해서 좌표가 밀리지 않게 했습니다.
- 사진은 CSS `object-fit: cover`와 같은 방식으로 잘라 그렸습니다.
- 문구가 영역을 넘치면 잘리는 대신 글자 크기를 줄여 다시 계산합니다.

입력 쪽에서는 지원하지 않는 파일을 올리거나 이상한 값이 들어와도 기존 작업은 그대로 두고 거부 이유만 보여 주게 했습니다. 투명 PNG는 배경을 칠하지 않아서 투명도가 유지되고, canvas로 다시 그리기 때문에 원본 사진의 위치 정보(EXIF)는 저장 파일에 남지 않습니다.

템플릿은 배열 순서가 아니라 고유 id로 찾게 해서, 순서가 바뀌어도 엉뚱한 템플릿이 수정되지 않습니다. JSON을 가져올 때는 형식 검사를 모두 통과해야만 저장하고, 실패하면 기존 템플릿은 건드리지 않습니다.

## 알려진 문제

탭 4 · 5의 템플릿은 새로고침하면 사라집니다. 처음 만들 때 Claude 아티팩트 화면 안에서만 있는 저장 기능(`window.storage`)을 썼는데, 일반 브라우저에는 그 기능이 없기 때문입니다. 위 바로 보기 링크에서도 템플릿을 저장하면 "저장에 실패했어요"가 뜹니다.

이 문제는 [MK5](../MK5_ai-handoff-experiment/)에서 원인을 찾아 고쳤고, 고친 과정 자체를 실험으로 기록했습니다. 이 폴더는 고치기 전 상태를 그대로 남겨 둔 것입니다.

## 실행

```bash
npm install
npm run dev
```

Claude와 대화하면서 만들었고, 탭 구성과 확인할 입력 12가지, 미리보기와 결과물이 맞는지는 직접 정하고 확인했습니다.
