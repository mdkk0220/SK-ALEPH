# MK3 · 팬카드 스튜디오

SK ALEPH 부트캠프 실습 (2026-09-14). 문구 · 크기 · 색 · 비율(1:1, 4:5, 9:16)을 정해 팬카드를 만드는 React 앱입니다. 기능을 탭 다섯 개로 나눴습니다.

| 탭 | 내용 |
|---|---|
| 1 | 편집과 미리보기 |
| 2 | 화면과 파일의 일치 |
| 3 | 극단 입력 12건 |
| 4 | 실제 템플릿 관리 |
| 5 | 옮겨 쓰기와 완성본 |

```bash
npm install
npm run dev
```

탭 4 · 5의 템플릿이 새로고침하면 사라지는 문제는 [MK5](../MK5_ai-handoff-experiment/)에서 고쳤습니다.
