# MK2 · 도지 러너

[바로 플레이](https://aleph-mk0909.vercel.app) · 2026-09-09 · HTML, CSS, JavaScript

위에서 떨어지는 장애물을 피해 30초를 버티는 8비트 브라우저 게임입니다. 목숨은 3개이고, ← → 또는 A / D로 움직입니다.

## 기능

| 항목 | 내용 |
| --- | --- |
| 난이도 | 하 · 중 · 상. 낙하 속도가 110, 140, 190으로 달라집니다 |
| 접근성 설정 | 효과음 끄기, 화면 흔들림 끄기 |
| 저장 | 난이도, 설정, 플레이 기록이 새로고침 후에도 남습니다 |
| 기록 | 최근 20판을 표로 보여 주고 CSV로 내려받을 수 있습니다 |

## 신경 쓴 부분

저장값이 깨져도 게임이 멈추지 않게 했습니다. 브라우저 저장소(`localStorage`)는 사용자가 지우거나, 다른 탭에서 덮어쓰거나, 아예 막혀 있을 수 있습니다. 그래서 읽기와 쓰기를 모두 `try / catch`로 감싸고, 읽은 값이 올바른 JSON이 아니면 기본값으로 시작하게 했습니다.

이걸 직접 확인할 수 있도록 화면에 시험용 버튼 두 개를 넣었습니다. 하나는 저장값을 비우고, 하나는 일부러 깨진 문자열을 저장합니다. 누르고 새로고침하면 게임이 정상으로 뜨는지 바로 볼 수 있습니다.

CSV는 엑셀에서 한글이 깨지지 않도록 파일 앞에 BOM을 붙였습니다.
