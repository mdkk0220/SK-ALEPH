# MK1 · 자기소개 웹 페이지

[바로 보기](https://aleph-mk0908.vercel.app) · 2026-09-08 · HTML, CSS

부트캠프 과제로 만든 한 장짜리 자기소개 페이지입니다. 기술 스택과 지금까지 한 프로젝트 세 개(자세교정 시스템, 켈그린 등급 관절염 분류기, 익명 질문 시스템 Shydent)를 정리했습니다.

## 만든 방식

프로젝트마다 상황, 행동, 결과 순서로 적었습니다. 읽는 사람이 "무슨 문제였고, 내가 뭘 했고, 어떻게 끝났는지"를 같은 자리에서 찾을 수 있게 하려는 목적이었습니다.

결과 아래에는 확인할 수 있는 근거를 붙였습니다. 서버를 이미 내린 프로젝트는 그 사실을 같이 적었습니다. 예를 들어 웹캠 분석 백엔드는 종료돼서 화면 UI만 볼 수 있고, Shydent는 GCP 무료 기간이 끝나기 전에 구독을 취소해서 지금은 운영하지 않습니다.
